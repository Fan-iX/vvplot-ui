# VVPlot-UI

UI library for [VVPlot](https://fan-ix.github.io/vvplot/) and [VVTree](https://fan-ix.github.io/vvtree/).

## Development

`node` and `npm` are required for development.

to start a development server, run:

```sh
npm install
npm run dev
```

to compile the library, run:

```sh
npm run build
```
